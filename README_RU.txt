WaveMusic PWA — версия для установки на iPhone без компьютера

ВАЖНО
Это веб-приложение (PWA), а не нативный IPA. Оно не требует подписи Apple и может быть добавлено на экран «Домой» из Safari после публикации на HTTPS-сайте.

Публикация через GitHub Pages:
1. Откройте https://github.com/ в Safari и войдите в аккаунт (создайте бесплатный, если нужно).
2. Создайте новый публичный репозиторий, например wavemusic.
3. Нажмите Add file → Upload files и загрузите ВСЕ файлы из этой папки, сохранив структуру.
4. Откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch, branch main, folder /(root), нажмите Save.
6. Дождитесь публикации; адрес будет вида https://ВАШ-ЛОГИН.github.io/wavemusic/.
7. Откройте адрес именно в Safari на iPhone → кнопка «Поделиться» → «На экран Домой» → «Добавить».

Ограничения:
- Каталог и авторизация VK не подключены.
- Воспроизведение фоновой музыки в веб-версии зависит от iOS/Safari и может быть ограничено.
- Не вводите пароль Apple ID на сторонних сайтах.
